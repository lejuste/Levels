# Levels

Set a separate volume for each app on your Mac, from the menu bar.

- **Shows only apps playing sound.** Short notification sounds don't appear.
- **A slider and mute for each app, with up to 2× boost.** Settings are remembered for each app.
- **Starts at login and lives in the menu bar.** It follows your light or dark appearance.
- **Updates itself.** New versions install from the menu with Check for Updates.

Requires macOS 15 (Sequoia) or later. There's no audio driver to install: Levels uses the per-app audio capture built into macOS.

## Install
Download the latest `Levels-<version>.dmg` from [Releases](https://github.com/lejuste/Levels/releases/latest), open it, and drag **Levels** into **Applications**.

On first use, macOS asks for **System Audio Recording** permission, so Levels can adjust other apps' audio. Nothing is recorded or saved.
